# SDC3b Results Comparison

Tools for comparing the posterior probability distributions submitted by teams participating in the [SKA Data Challenge 3b (SDC3b)](https://sdc3.skao.int/).

Each team produced a 3D posterior grid over the neutral hydrogen fraction $x_\mathrm{HI}$ at three redshift bins, inferred from simulated 21-cm power spectra.

---

## Setup

### Install dependencies

```bash
pip install -r requirements.txt
```

### Required data (not included in the repository)

> **Important:** The following two folders are listed in `.gitignore` and are **not** included in the repository. Place them in the root of this project before running any scripts or notebooks.

```
sdc3b_results_comparison/
├── mocks/          ← team submission FITS files (gitignored)
│   ├── Team_1/
│   │   └── Team_1_PS1.fits
│   ├── Team_2/
│   │   └── Team_2_PS1.fits
│   └── ...
├── Truth/          ← ground-truth text files (gitignored)
│   ├── True_valuesPS1.txt
│   ├── True_valuesPS2.txt
│   ├── True_valuesPS3.txt
│   ├── True_xh_z_PS1.txt
│   ├── True_xh_z_PS2.txt
│   └── True_xh_z_PS3.txt
└── ...
```

The `mocks/` directory must follow the naming convention `mocks/Team_<N>/Team_<N>_<PS>.fits` where `<N>` is the team number (1–26) and `<PS>` is the power spectrum bin (`PS1`, `PS2`, or `PS3`).

---

## Files

| File | Description |
|------|-------------|
| `sdc3b_mock_posteriors.ipynb` | Main analysis notebook. Loads posteriors for all 26 teams, overlays corner plots, and computes ranking metrics (Z-score, Mahalanobis distance, PIT, credible interval coverage). |
| `process_posteriors_for_html.py` | Pre-processing script. Reads all team FITS files, computes 1-D and 2-D marginals, and writes `posteriors_data.js` which is required by `compare_posteriors.html`. Only needs to be re-run if the `mocks/` folder changes or `posteriors_data.js` is not present. |
| `compare_posteriors.html` | Interactive browser-based posterior viewer. Must be kept in the same directory as `posteriors_data.js`. No server needed — open directly in a browser. |
| `posteriors_data.js` | Pre-computed marginals for all teams (generated by `process_posteriors_for_html.py`). Included in the repository so the HTML viewer works without re-running the script. |
| `requirements.txt` | Python package dependencies. |

---

## Usage

### Interactive notebook

```bash
jupyter notebook sdc3b_mock_posteriors.ipynb
```

### HTML viewer

`posteriors_data.js` is already included in the repository, so you can open `compare_posteriors.html` directly in a browser without running any script.

> **Note:** Only re-run `process_posteriors_for_html.py` if the contents of `mocks/` have changed or `posteriors_data.js` is missing:
>
> ```bash
> python process_posteriors_for_html.py
> ```
>
> `compare_posteriors.html` and `posteriors_data.js` must be in the same directory.
